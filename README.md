# 中国地铁列车驾驶模拟器

一个运行在浏览器里的北京地铁 19 号线驾驶台模拟器。当前版本以 8 节 A 型车、接触网 DC1500V 和 CBTC 移动闭塞为基础，组合了车载 DMI、TCMS、驾驶台、速度—距离曲线、ATP/ATO、ATS/OCC 中心工作站与简化纵向动力学模型。

> 仅用于界面演示、教学讨论和交互体验，不可用于实际培训、考试、调试或运营决策。

![驾驶台总览](images/demo/photo_01.png)

## 快速开始

本项目是纯静态前端，没有构建步骤和运行时依赖。推荐用本地静态服务器打开，避免浏览器对 `file://` 下 ES Module 与 iframe 的限制。

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000/          # 驾驶台（主界面）
http://localhost:8000/ats-occ/  # ATS 中心工作站（独立页面）
```

部署时请保留完整目录结构，尤其是 `vobc-dmi/` 和 `tcms-dmi/`，主界面会通过 iframe 加载这两个屏幕。

需要单独检查屏幕或注入模拟状态时，也可以直接访问：

```text
http://localhost:8000/vobc-dmi/  # 车载信号 DMI 与 25 区调试器
http://localhost:8000/tcms-dmi/  # TCMS 与打桩调试器
```

## 模拟内容

### 驾驶台

- Tc1/Tc2 两端驾驶台共用同一套车载 ATP/ATO/TCMS 核心状态，但各自拥有司机钥匙和 DMI 接口；控制权按钥匙激活顺序“先到先得”。另一端钥匙仍可转到 ON，但不会取得牵引、制动和信号操作权；此时激活端 VOBC 第 7 区显示“本端激活 / 对端故障”，后开端显示“本端故障 / 对端激活”。当前控制端在停稳、主控手柄归零且方向手柄置于 N 位后关闭钥匙，已处于 ON 的另一端自动接管。
- 右屏为重新设计的 TCMS 列车监控界面，显示 8 节 A 型车编组、下一站和终点、速度、电流、网压、运行模式、牵引/制动百分比、主风缸/制动缸压力、受电弓、逐车车门、乘客率、客室温度和实时事件日志。
- 下方为可交互的 ATS 线路与速度—距离图，展示站台、信号机、应答器、限速区段、列车位置和移动授权，并同时绘制列车最高运行速度、最高限制速度、ATP 限制速度、推荐速度、ATO 运行速度和 EB 触发速度。
- 线路图支持放大、缩小、跟随列车、恢复全线、滚轮定位缩放，以及逐条显示/隐藏速度曲线和 ATO/ATP 预设。

![控制台细节](images/demo/photo_02.png)

### TCMS 列车监控与调试

- 主界面以约 80 ms 的节流间隔向 TCMS 同步车辆状态，系统消息和报警也会写入 TCMS 日志区。
- 编组显示支持 4、6、8 节配置；当前线路默认采用 `Tc1-Mp1-M1-Mp3-M3-M2-Mp2-Tc2` 8 节编组，每节每侧 5 对车门。
- 车体图会分别反映车门开闭、制动状态、HSCB/BCM 标识、受电弓升降和车辆首尾方向。
- 独立打开 `tcms-dmi/` 时可使用打桩调试器，调整速度、网压、电流、牵引/制动、风压、运行模式、供电、空调、EB、报警、车门、车次和站名。
- 调试器还支持逐车修改车号、开门侧、受电弓、制动缸压力、牵引力、乘客率、温度及 A/B 侧车门编号，并可注入 Info、OK、Error 日志。

### ATS 中心工作站（OCC）

独立的调度大厅工作站界面（`ats-occ/`），独立于驾驶台打开，用于从控制中心视角监视全线站场。

- **站场图**：19 号线正线（牡丹园 — 新宫）双线示意，区段、道岔、信号机、站台门、控制模式和列车车次窗按《城市轨道交通信号系统运营技术规范（试行）》附件 B 的符号与推荐 RGB 色值显示；道岔点位为界面演示示意，不宣称为现场实设数据。
- **状态条**：ATS 主机、ATP 轨旁、CI 联锁、DCS 通信等关键设备状态，以及北京时间时钟。
- **运行图**：时刻—里程格式的列车运行图。
- **报警面板**：报警信息表，支持单条 / 全部确认。
- **站场操作**：全线缩放、跟踪列车、元素名称显隐；站场图可拖拽平移。
- 通过左上角「返回驾驶台」回到主界面。

### 区段最高限制速度编辑器

驾驶台线路图下方新增“列车运行最高限制速度”表格，可修改各区段起点、终点和绝对速度上限。

- 输入会校验在全线里程范围内，并要求 `起点 < 终点`、区段互不重叠且最高限制速度不低于该区段最高运行速度；允许保留未覆盖区间。
- 点击“应用”后，ATP、ATO、DMI 和速度曲线会共同采用新上限；列车超过该绝对上限会触发紧急制动。
- 点击“恢复默认”会按线路速度重新生成默认上限，并统一钳制在当前 100 km/h 运营上限内。
- 系统重置时会同时恢复默认限速表和全线视图。

### 控制设备

- 左侧辅助区：带钥匙位置反馈的司机钥匙 ZK、头灯、司机室灯、客室灯、空调、雨刮低/高速、左右开门、左右关门和鸣笛。
- 中央主控区：方向手柄 F/N/R 与主控手柄 TBC，支持牵引、惰行、常用制动和快速制动。
- 右侧信号区：ATO 启动、模式升级/降级、确认、车门允许、跳停、扣车、门模式、最高驾驶模式和紧急制动按钮。
- 列车必须停稳且主控手柄归零后才能换向；方向手柄在 N 位时主控手柄只能保持零位。

### 驾驶模式

- `RM`：限制人工驾驶，最高 25 km/h。
- `CM`：ATP 防护下的人工驾驶。
- `AM`：ATO 自动驾驶，按推荐速度曲线运行并自动对标停车。
- `FAM`：全自动运行模式，配合 A/A 门模式可自动完成开关门和续行。

## 基本操作

1. 确认司机钥匙 `ZK` 为 `ON`。
2. 将方向手柄置于 `前进 F`。
3. 默认进入 `RM`，可通过“模式升级”切换到 `CM`、`AM` 或 `FAM`。
4. 人工驾驶时拖动主控手柄，向上牵引，向下制动。
5. 在 `AM` 或 `FAM` 中，手柄回零、车门关闭、无 EB、无扣车且移动授权满足后，按“ATO 启动”。
6. 到站后根据门模式和 ATP 允许开门；乘降结束后关门，等待允许启动后继续运行。
7. 触发 EB 后列车会施加紧急制动；停稳并回零后可再次按 EB 按钮缓解。

## 快捷键

- `W` / `S`：主控手柄增加或减少 10%。
- `Q` / `E`：驾驶模式升级或降级。
- `Enter`：ATO 启动。
- `Esc`：紧急制动或缓解。
- `H`：鸣笛。

## 系统特性

- 车辆参考北京地铁 19 号线 8 节 A 型车，采用接触网 DC1500V 受流设定。
- 信号系统参考 CBTC 移动闭塞逻辑，包含区段绝对上限、ATP 动态限制速度、最大常用制动触发速度、EB 触发曲线和站内停车曲线。
- ATP 的 EB 曲线计入 1.2 s 系统/车辆响应延时、保证紧急制动率和测速误差裕量；AM/FAM 可先施加最大常用制动，CM 则保留 ATP 紧急制动防护。
- ATO 只输出牵引/制动加速度，列车位置与速度由物理引擎积分得到，不直接修正列车坐标；指令带车体响应滤波和冲击率限制。
- ATO 采用牵引加速、波动带巡航、曲线制动、低速蠕动四段控制，并对前方降速点和车站停车点共同计算速度剖面。
- ATO 正常运行图目标取区段上限的 85%，为晚点恢复保留速度余量；A/A 停站基线为 35 s，全线时分按约 30 min 标定。
- 对标停车窗约为 ±30 cm；窗外 5 m 内可按不高于 5 km/h 的跳跃方式前后调整，最多 3 次。FAM 运行中过标超过 1 m 会触发 EB，停稳后依据偏差决定自动回调或等待人工处置。
- A/A 支持自动开关门与续行；扣车时重新联动车门/站台门并保持，终点站乘降完成后退出 ATO。
- 门控支持 `M/M`、`A/M`、`A/A`，并区分 ATP 站台侧门允许与人工两侧门允许。
- 简化物理模型包含 8A 空载质量与乘客载荷、40 km/h 后恒功率牵引衰减、坡度与曲线阻力、滚动与空气阻力、电空混合制动、低速再生衰减和制动建压滞后；人工制动停稳时会消除过零反向加速。

### 19 号线线路数据

## 主要参数

- 最大牵引加速度：`1.0 m/s²`
- 车辆设计速度：`120 km/h`
- 当前运营速度上限：`100 km/h`
- 最大常用制动：`1.1 m/s²`
- 紧急/快速制动：`1.3 m/s²`
- RM 限速：`25 km/h`
- ATP 超速 EB 裕量：限速 + `5 km/h`
- ATO 停车对标容差：约 `±30 cm`
- 仿真主循环：`30 Hz`

### ATP、ATO 与物理模型

- 依据《城市轨道交通列车运行速度控制导则》《城市轨道交通全自动运行系统建设指南》及 GB/T 12758-2023，重写速度监督链和进站控制。
- **ATP 五级监督链**：列车最高运行速度 → 列车运行最高限制速度 → ATP 系统限制速度 → 最大常用制动触发速度 → 紧急制动触发速度；EB 曲线计入 1.2 s 响应延时、保证制动率和 5 km/h 测速误差裕量。
- **分模式干预**：AM/FAM 超过常用制动触发速度时先由 ATP 施加最大常用制动，达到 EB 阈值或绝对上限时触发紧急制动；CM 保持人工控速并由 EBI 提供最终防护。
- **ATO 四段控车**：牵引加速 → ±2 km/h 波动带巡航 → 沿曲线制动 → 末端低速蠕动对标；前方降速区段与停车点统一进入运行速度剖面，指令加入冲击率限制。
- **跳跃对标**：停车窗约 ±30 cm，窗外偏差不超过 5 m 时以不高于 5 km/h 前后调整，最多 3 次；超次保持制动并报警。
- **过标防护**：FAM 运行中过标超过 1 m 自动触发 EB；停稳后偏差不超过 5 m 时自动缓解并向后调整，超过 5 m 则保持 EB 等待人工处置。
- **站台作业**：A/A 自动开关门和发车，扣车时重新开门并保持，取消扣车后恢复作业；终点站乘降完成后退出 ATO。
- 重写纵向动力学中的制动建压、零速保持、反向运行、进站停车和人工制动停稳逻辑，消除零速附近因滤波余量造成的反向“幻象牵引”。
