# Security Policy

## Reporting a Vulnerability

This project is currently a client-side web application and does not collect or store user data.

If you discover a security vulnerability, please do not create a public GitHub Issue.

Instead, please report it privately through GitHub Security Advisories:

https://github.com/OWNER/REPOSITORY/security/advisories/new

Please include:

- A description of the issue
- Steps to reproduce
- Affected files or versions
- Potential impact

We will review security reports and respond when possible.

## Scope

Security reports may include:

- Malicious code execution risks
- Cross-site scripting (XSS)
- Dependency vulnerabilities
- Issues that may affect user security

The following are generally not considered security vulnerabilities:

- General bugs
- Feature requests
- Visual or performance issues without security impact

Thank you for helping improve this project.
